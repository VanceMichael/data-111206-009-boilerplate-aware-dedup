# 授权资讯原页采集、正文判别与近重复处理

提取带 DOM 路径的可见文本块，按来源站点学习模板噪声，并在保留下来的正文片段上做可解释的近重复归组。

## 运行

在 Python 3.11 或更新版本的 Linux 环境使用，仅依赖标准库。原始内容与判断结果保存在 `output/raw.sqlite3`，删除 `output/` 可回到干净状态。全部示例使用本地合成数据，不包含账号凭据或真实企业资料。

```sh
python3 -m unittest discover -s tests -v
python3 -m compileall -q .
python3 app.py demo
python3 app.py query --article north-1
python3 app.py query --pair north-1,south-copy
```

`app.py demo` 跑整批与固定种子打乱的逐篇增量两条路径，输出模板模型、内容组、代表稿、差异证据入口与实际候选比较数量，并断言两条路径结果一致。`query` 从 SQLite 直接查询内容组、正文版本与成对证据。

## 处理流程与规则版本

所有判别绑定同一个规则版本 `rules-1.0.0`（见 `boilerplate.py` 与 `near_duplicate.py`）。编辑只提供阈值（`fixtures/truth.json`，当前 0.55）与少量确认样例，不提供逐对答案。

1. **原文保存（`raw_store.py`）**：原始字节按 SHA-256 存对象，观察按（来源，摘要）登记；相同字节共享对象，任何重算都不改写原件。
2. **文本块提取（`text_source.py`）**：每个可见文本块带 DOM 路径与顺序 ordinal，隐藏节点与 script/style 不产出块。
3. **模板学习（`boilerplate.py`）**：按（站点，页面类型）分别从多页样本学习。列表页、详情页、代码示例各自独立建模；同一（站点，类型）样本少于 3 页时返回保守模型，不剥离任何块。规则候选要求（路径，文本）在至少 75% 的样本页重复出现；正文容器（main/article）内的块与不超过 12 字的短块（短公告、公司名、金额单位等）在学习阶段即受保护，不会被删。
4. **正文版本（`content_store.py`）**：剥离记录保留 DOM 路径、ordinal 与命中的模型指纹。正文版本只追加；仅当模板指纹或原文摘要变化时才新增版本。站点改版后模板指纹变化，受影响文章自动进入待重算列表，从原文对象重新抽取，旧模板版本、旧正文版本与既有观察全部保留。
5. **近重复判断（`near_duplicate.py`）**：只对保留下来的正文片段（标题 h1-h3 不参与，避免转载换标题干扰）生成 4 字 shingle，用 Jaccard 相似度与编辑阈值比较。每对候选都落证据：重合片段、双方独有片段、分数、阈值与判定理由。
6. **候选检索**：shingle 倒排索引持久化在 SQLite，候选只在共享 shingle 的文章之间产生，不逐对扫描整库；编辑确认对与相同字节对强制纳入。每次运行统计并报告索引候选数、约束对数、实际打分数与全量逐对上限。

## 组内约束与代表稿

近重复归组明确禁止链式误合并：

* 同稿边必须有**直接证据**（相似度达阈值、编辑确认同稿或字节完全相同）。甲≈乙、乙≈丙不会推出甲≈丙。
* 同一连通分量只有在构成**团**（任意两篇之间都有 same 边）时才形成 `unique` 组；否则标记 `ambiguous`，记录缺失直接证据的文章对，保留歧义，不碰巧取第一个。
* 代表稿按确定性规则选择：保留正文最长者优先，长度相同取文章 id 字典序最小。组 id 由成员集合哈希得到，与入库顺序无关。
* 逐篇入库、乱序入库与整批重算共用同一规则与同一归组函数，测试断言三者在组 id、成员、代表稿与成对证据上完全一致。

## 数据模型

`content_store.py` 在原文库同文件新增表，不改动 `objects/observations`：

| 表 | 作用 |
| --- | --- |
| `template_models` | 每（站点，类型）的模板版本历史与规则集 |
| `content_versions` / `article_current` | 只追加的正文版本与当前版本指针 |
| `shingle_postings` | 持久化倒排索引，与版本切换在同一事务更新 |
| `editor_constraints` | 编辑确认的同稿/不同样例 |
| `judge_runs` / `pair_evidence` | 每次判断运行的统计与成对重合/差异证据 |
| `content_groups` / `group_members` | 内容组、歧义标记与代表稿 |

## 合成语料

`fixtures/corpus` 为自写合成 HTML：`north-*` 详情页含重复导航与免责声明、短公告与同稿转载；`north-list-*` 演示列表页独立模板（含列表工具栏）；`south-copy` 是只换站点与标题的转载；`chain-a/b/c` 构成相邻相似但不传递的相似链；`sample-code` 是代码示例页，样本不足时走保守策略。`fixtures/truth.json` 仅提供一条确认同稿、一条确认不同与阈值。

## 环境

`requirements.txt` 登记精确依赖（仅标准库）。环境准备阶段安装依赖，运行、构建及测试不执行下载。
